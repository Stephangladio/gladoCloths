# GLADO — E-Commerce Web Application

A responsive clothing e-commerce frontend built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. GLADO demonstrates a modern online shopping experience, from browsing products to managing a wishlist and cart, completing a demo checkout, and viewing an order confirmation.

## Live Demo

**Website:** https://glado-cloths.vercel.app/

## Features

- **Product browsing** — explore the clothing collection through product listing and detail views.
- **Search and discovery** — search products, filter by category, and sort the product list.
- **Product details** — view individual product information before adding items to your shopping bag.
- **Shopping cart** — add and remove products, update quantities, and review cart contents.
- **Wishlist** — save products to a wishlist for later.
- **Persistent state** — cart and wishlist information are stored in the browser using LocalStorage.
- **Checkout flow** — proceed through checkout with a demo payment experience and order confirmation.
- **Responsive interface** — layouts and navigation designed for desktop, tablet, and mobile screens.
- **Reusable components** — shared UI components and routed pages help keep the application organized.

> **Note:** This is a frontend demonstration project. The checkout/payment flow is for demonstration purposes and does not process real payments.

## Getting Started

Follow these steps to run GLADO locally.

### Prerequisites

- Node.js (a current LTS version is recommended)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Stephangladio/gladoCloths.git
```

### 2. Open the project folder

```bash
cd gladoCloths
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal by Vite (usually http://localhost:5173).
